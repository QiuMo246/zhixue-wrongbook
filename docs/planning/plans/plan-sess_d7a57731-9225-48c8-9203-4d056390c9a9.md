# 智学网错题助手 · 宣传网页计划

## 视觉基调（已锁定：红笔订正·错题本）

**设计模式**：Persuade（宣传页）——首屏 3 秒内让学生明白「这是什么、对我有什么用、点哪」。拒绝 AI 模板味（不用奶油底+衬线+陶土红的老三样，不用黑底霓虹）。

**配色（Committed 策略，一个饱和色承担主要视觉）**
| 角色 | 值 | 用途 |
|---|---|---|
| 纸白底 | `#FBFAF6` + 极淡方格纹理（CSS 画，像作业本） | 全页背景 |
| 墨蓝 | `#1E2A44` | 正文、标题 |
| **订正红** | `#E0453A` | 主色：CTA 按钮、关键词、数字、流程节点 |
| 荧光黄 | `#FFE24A` | 划重点标记（文字背景高亮，用得克制） |
| 铅笔蓝 | `#3A7BD5` | 链接、次级信息 |

**字体**
- 标题：自托管中文字体子集（MiSans 或思源黑体 Heavy，只子集化标题用到的几十个字，woff2 几十 KB）——标题有独特表情
- 正文：系统栈（`system-ui, "Microsoft YaHei", "PingFang SC", sans-serif`）零加载成本
- 命令/代码块：`Consolas / Cascadia Code` 等宽栈

**标志性细节**：错题本隐喻贯穿——荧光笔高亮关键词、红笔「订正」符号（√/×）做列表标记、聊天气泡像作业本上的批注、虚线裁切线做板块分隔。

## 页面结构（单页，从上到下）

1. **Hero 首屏** — 项目名 + 大标题「把错题，变成你的专属练习卷」（荧光黄高亮「专属练习卷」），主按钮 **「从 Gitee 安装（不用翻墙）」**，GitHub 弱化次按钮
2. **功能板块**（只写 README 里真实存在的功能）：错题自动同步（三通道一句话带过）/ 错因分析+知识点标注（8 类错因、341 知识点词表）/ 薄弱项诊断（强制先问科目+试卷范围）/ 同类题练习+自动批改 / 报告导出 / 隐私底色一句话
3. **使用方法板块 —— 面向没听说过 GitHub/Gitee 的学生，从零解释**
   - 大白话解释：「GitHub 和 Gitee 都是放代码的网站，像两个网盘，这个项目在两边各放了一份，内容完全一样」
   - **怎么选（对比卡）**：**Gitee = 国内网站，不用翻墙、速度快 → 不会翻墙 / 不知道翻墙 / GitHub 打不开转圈 → 用它（默认推荐）**；**GitHub = 国外网站，国内直连经常打不开；有翻墙工具再用**。结论一句话：**拿不准就用 Gitee**
   - **懒人安装法（主推）**：可一键复制的「发给 AI 助手」整段话（Gitee 地址在前），附「没装 Python → 用 AI 自带的 / install.bat」「没装 git → --from-zip」说明
   - **手动安装**：五步精简版
4. **使用流程演示** — 聊天气泡模拟真实对话：「帮我同步错题」→ 助手反问科目/卷子范围 → 诊断 → 出练习卷 → 批改报告
5. **FAQ**（折叠面板）：需要什么账号、会不会封号、支持哪些 AI 助手、数据存哪、换电脑怎么办、**GitHub 打不开怎么办→换 Gitee**、题干会发给 AI 吗（如实：会，介意就用本地模型）
6. **Footer** — 双仓库链接、「已知局限诚实清单」入口、开源说明
