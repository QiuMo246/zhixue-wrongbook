# 智学网错题助手 · Remotion 宣传片计划

**成品**：60 秒 · 1920×1080 · 30fps · 无声 MP4（H.264），输出到 `zhixue-wrongbook/promo-video/out/promo.mp4`

## 一、项目搭建

新建独立目录 `zhixue-wrongbook/promo-video/`（不碰 Vue 官网），`npm init` 后装 `@remotion/cli` + `remotion` + `misans`（复用官网同款 MiSans 字体包，用 `staticFile()` 加载 woff2）。

## 二、视觉规范（对齐官网「红笔订正·错题本」主题）

直接从 `web/src/style.css` 提取设计 token 做成 `theme.ts`：

- 纸白背景 `#fbfaf6` + 30×30 方格作业本纹理线（rgba(30,42,68,.045)）
- 墨蓝 `#1e2a44` / 订正红 `#e0453a` / 荧光黄 `#ffe24a` / 铅笔蓝 `#3a7bd5`
- 硬阴影纸片：`4px 4px 0 rgba(30,42,68,.9)`，按钮 2px 描边圆角 10px，卡片歪斜 rotate(∓0.4°~1.6°)
- 标题 MiSans 900，正文 system-ui

## 三、分镜脚本（约 1800 帧，9 个场景）

1. **开场 0–6s**：方格纸上一张「物理·午练·第 9 题 得 0/3 分」错题卡砸落，大红「×」盖下来，kicker「给初中生的错题本外挂」逐字弹出
2. **标题 6–12s**：H1「把智学网的错题，变成你的专属练习卷」，荧光黄高亮从左划到右
3. **对话① 同步 12–19s**：聊天气泡「帮我同步错题」打字机出现 → 三条通道徽章（官方导出/现成库/自建接口）依次弹入 + 「同步完成 ✓」
4. **对话② 诊断 19–27s**：「帮我分析薄弱项」→ 诊断闸门红框卡片弹出「不问清范围，不给数据」→ 用户补答「九上物理，近三次考试」→ 画像生成
5. **对话③ 出卷 27–35s**：练习卷卡片展开，「浮力」等薄弱知识点荧光黄划过，题目逐条落位
6. **对话④ 批改 35–42s**：「做完帮我批改」→ 红笔大「✓」rotate(-8°) 盖章 +「答案回代验算通过」
7. **数字快闪 42–49s**：26 工具 / 8 类错因 / 341 知识点 / 328 项自检，四张纸片卡依次拍上
8. **隐私 49–54s**：「数据全在你自己电脑上」+ 凭据进系统凭据管理器小图标
9. **结尾 CTA 54–60s**：红实心按钮「复制安装提示词」拍落 + 硬阴影浮现 + Gitee 地址 `gitee.com/qiu_moRs/zhixue-wrongbook`

## 四、动效语言

全部用 Remotion `spring()` 弹入 + `interpolate()`：卡片拍落（y+scale overshoot）、打字机文字（逐字 opacity）、荧光笔划线（宽度 0→100%）、红笔盖章（scale 1.6→1 + 轻微 rotate）、红圈圈错题（stroke-dashoffset 描边动画）。卡片交替 ±0.4° 歪斜还原官网手写感。

## 五、结构与验证

- `Root.tsx` 注册 `PromoVideo` 组合，每个分镜一个组件文件（`scenes/Scene1Intro.tsx` …），共享 `theme.ts` + `NotebookBackground.tsx` + `DialogueBubble.tsx`
- `npx remotion studio` 本地预览调试
- 渲染帧导出 PNG 交给视觉审查 agent 验收（配色/字体/构图对齐官网），通过后 `npx remotion render` 出最终 MP4

执行顺序：初始化项目 → theme/背景/公共组件 → 逐场景实现 → studio 自查 → 视觉验收 → 渲染 MP4。
